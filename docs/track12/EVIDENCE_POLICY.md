# Public Evidence Publication Policy

Only reviewed summaries, methodological restrictions and file hashes are
published here. Source archives, raw console logs, credentials, hidden labels,
third-party private code, model response payloads and personal data are NOT
published by this update.

SHA-256 indexes establish fingerprints of local originals and independently
verified local backups, not open availability of original artifacts.

Frozen source worktrees, prior research histories, and `main` are unchanged.
The draft pull request is review-only; merge requires a separate decision.
