Looking at the developer change description, I need to implement functionality to fix restoring voucher usage limit when a voucher is removed from a draft order. The key points are:

1. Reduce the voucher limit when the voucher is removed from draft order
2. Fix updating the voucher usage_limit 
3. Ensure that voucher usage is released when the voucher code is removed from draft order

Let me analyze the current code to understand how vouchers are handled in draft orders and identify where the fix needs to be implemented.

From examining the code, I can see that:
1. In `draft_order_create.py`, there's handling for voucher usage increase when a voucher is added to a draft order
2. In `draft_order_update.py`, there's similar handling but no logic to decrease usage when a voucher is removed
3. The voucher update mutation has validation around usage limits but doesn't handle release logic

The main issue appears to be that when a voucher is removed from a draft order, the usage count is not decreased. I need to add logic to handle this case.
