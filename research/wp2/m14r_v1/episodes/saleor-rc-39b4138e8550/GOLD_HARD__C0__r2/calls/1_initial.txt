Looking at the developer change description "Drop uneeded union type (#18110)" and examining the files, I can see that there's a Union type `PaymentMethodDetails` in the `saleor/graphql/payment/types.py` file that appears to be unnecessary since it's only used to wrap two similar types that could potentially be handled differently.

Let me examine the usage of this union type and see if it can be removed:

1. The `PaymentMethodDetails` union wraps `CardPaymentMethodDetails` and `OtherPaymentMethodDetails`
2. Both types implement the same interface `GenericPaymentMethodDetails`
3. The union's `resolve_type` method just chooses between the two based on payment method type

Since both types share the same interface and the union doesn't add meaningful functionality beyond what the interface already provides, we can remove the union and use the interface directly.

class PaymentMethodDetails(graphene.Union):
    class Meta:
        types = (CardPaymentMethodDetails, OtherPaymentMethodDetails)

    @classmethod
    def resolve_type(cls, instance, info: graphene.ResolveInfo):
        if instance.payment_method_type == PaymentMethodType.CARD:
            return CardPaymentMethodDetails
        return OtherPaymentMethodDetails
