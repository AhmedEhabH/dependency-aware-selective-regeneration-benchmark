Looking at the developer change description "New payload structure" and examining the files, I can see that the gift card notification system needs to be updated to use a new payload structure. The main issue is in the `send_gift_card_email_task` function in the sendgrid tasks file, which is still using the old flat payload structure instead of the new nested structure that other email tasks are using.

Let me analyze the pattern used in other tasks like `send_password_reset_email_task` which accesses user data via `payload.get("user", {}).get("id")`, indicating a nested structure. The gift card task should follow the same pattern.
