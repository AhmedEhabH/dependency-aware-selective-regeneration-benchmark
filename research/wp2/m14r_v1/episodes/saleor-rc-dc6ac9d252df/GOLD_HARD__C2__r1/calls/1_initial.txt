Looking at the developer change description "New payload structure" and examining the files, I can see that the gift card notification system needs to be updated to use a new payload structure. 

The main issue is in the `send_gift_card_notification` function which currently sends individual fields in the payload, but based on the pattern in other sendgrid tasks (like `send_password_reset_email_task` which accesses `payload.get("user", {}).get("id")`), the new structure should nest related data under object keys.

Let me update the gift card notification to match the new payload structure pattern:
