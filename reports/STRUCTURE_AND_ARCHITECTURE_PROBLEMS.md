### SP-01 — Duplicate `kaggle_upload/`

| Field | Value |
|-------|-------|
| Severity | **CRITICAL** |
| Exact paths | `<parent>/kaggle_upload/` vs `project/kaggle_upload/` |
| Evidence | Both directories exist with different content: inner has `.git/`, caches; outer has populated data/ |
| Cause | Legacy structure: outer bundle was created first, inner bundle later without cleanup |
| Current impact | Confusion about which bundle is authoritative |
| Risk to Kaggle execution | **High** — deploying from inner bundle without data would fail |
| Risk to reproducibility | **Medium** — stale outer bundle could be deployed by mistake |
| Risk to scientific evidence | **Low** — results from either bundle would be identical if code matches |
| Recommended correction | Delete outer `kaggle_upload/`; fix inner bundle (remove `.git/`, caches, populate data/) |
| Affected artifacts | AID-DEP-001, AID-DEP-002, AID-DEP-003, AID-DEP-004 |
| Unaffected artifacts | All source artifacts, scenarios, configs |
| Requires researcher approval | No (engineering decision) |
