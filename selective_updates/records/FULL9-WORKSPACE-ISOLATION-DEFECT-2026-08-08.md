## The defect

The real Kaggle Full-9 (`exp-20260807-205422`, runtime source `f7b1ebb`) completed
9/9 records but the independent audit **rejected** it as a stable scientific
matrix: 2 succeeded / 7 failed, 62 model calls / 76,858 tokens. Root cause: the
pre-fix isolation reused each strategy workspace across scenarios and
`_populate_workspace_source` **overlaid** the immutable snapshot onto the
previous scenario's workspace **without deleting stale generated files**. The
stale migration `todo/migrations/0004_task_priority.py` generated by scenario
001 therefore survived into scenario 002, where Django auto-generated a new
`0005_remove_task_priority_task_deleted_at` migration — contaminating the 002
and 003 records of the selective and iterative-repository-agent arms. The
rejected Full-9 remains **evidence only**; it is preserved, not deleted, and is
NOT the accepted aggregate.

## The exact reset contract (Commit A `7f2a450`)

`seven_arm_benchmark.py` now resets the workspace **source** to the exact
immutable snapshot before **every** scenario × strategy run:

- `_WORKSPACE_INFRASTRUCTURE_DIRS = frozenset({"runs", "tmp", "snapshots"})` —
  infrastructure directories are never treated as source.
- `_reset_workspace_source_from_snapshot(workspace_dir, snapshot_root)` replaces
  the old `_populate_workspace_source`: delete the workspace source tree
  (every symlink/file entry unlinked, every directory removed), then restage the
  snapshot. This removes stale generated files, not just overwrites them.
- `_skip_subdirs = frozenset({"_metadata", "manifests"})` for generated-command
  scans.
- `make_isolation` calls the reset for every arm workspace on every run, so each
  matrix cell starts byte-identical to the immutable snapshot and leaves zero
  residue for the next cell.
- Old `_populate_workspace_source` deleted.
