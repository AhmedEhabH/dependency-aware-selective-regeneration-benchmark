## Notebook compile correction (independent audit)

The independent audit of the published repository ZIP found that the canonical
and generated notebooks contained invalid Python code cells. The structural
notebook edit inserted real newline characters inside ordinary quoted string
literals, so three cells each raised `SyntaxError: unterminated string literal`
when compiled as Python:

```text
setup-cell             unterminated string literal (line 146)
exec-cell              unterminated string literal (line 26)
continuous-smoke-cell  unterminated string literal (line 27)
```

Root cause: invalid newline escaping in structurally edited cells. The missing
check was full Python compilation of notebook code cells. Example damage:

```python
print("
--- SMOKE DASHBOARD ---")
msg = "
".join(lines)
print("
".join(tail[-10:]))
```

Corrected to escaped newline sequences:

```python
print("\n--- SMOKE DASHBOARD ---")
msg = "\n".join(lines)
print("\n".join(tail[-10:]))
```

Every damaged string literal in the canonical notebook was repaired: dashboard
headings, per-run table heading, matrix heading, failure-causes heading,
actionable-error separators, `"\n".join(lines)`, continuous-precondition
messages, live-output heading, return-code line, and final console-tail joins
(11 constructs in `setup-cell`, 1 in `exec-cell`, 1 in `continuous-smoke-cell`).
The generated notebook is never edited by hand; it was regenerated by
`scripts/build_upload_bundle.py`. Regression added in `tests/unit/test_cli.py`:
`test_all_deployed_notebook_code_cells_compile` (parametrized over both
notebooks), which fails against `ae1c325` and passes afterward. All existing
notebook-content and parity tests retained.
